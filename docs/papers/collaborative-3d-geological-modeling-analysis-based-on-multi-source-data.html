Collaborative 3D geological modeling analysis based on multi-source data standard

Q. Zhang and H. Zhu

Engineering Geology, 246:233 - 244, 2018.

  • Manuscript

Summary

A collaborative workflow is proposed for constructing and using three-dimensional geological models from heterogeneous information. A common data standard brings borehole records, geological mapping, and rock-property measurements into a coordinated database. A combined Kriging procedure processes the available observations, after which geological modeling algorithms construct, display, and support further analysis of the resulting model. The framework emphasizes the sequence of data preparation and modeling operations so that information collected at different places or stages can contribute to a consistent geological representation. It also supports collaboration between different software tools used for modeling and visualization. Application to the Ma-luan mountain tunnel project in Guangdong, China, demonstrates the approach. The work addresses practical difficulties in integrating geological evidence for tunnel projects and aims to make the resulting models easier to interpret and update.
