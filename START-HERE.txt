个人学术网站：开始使用
====================

当前是 ZHANG, Qi 的英文网站初稿，已通过 GitHub Pages 公开发布。
正式网址：https://keyjone.github.io/
网站仓库：https://github.com/KeyJONE/keyjone.github.io
单位和研究方向采用你提供的信息，简介及资料链接参照已有澳门大学主页。

1. 看效果
直接双击 docs 文件夹内的 index.html。
公式已提前排版，字体和样式也保存在本地，不需要联网下载才能看。

2. 修改文字
用记事本或代码编辑器打开 site 文件夹里的 .jemdoc 文件，以 UTF-8 保存。
index.jemdoc 是首页，biography.jemdoc 是简介，research.jemdoc 是研究与公式示例，
software.jemdoc 是软件，MENU 控制左侧导航。
论文内容集中保存在 site/publications.json：包含标题、作者、首次在线年份、
期刊信息、Manuscript 和附加链接，以及摘要或标注为 Summary 的英文概述。
generate_papers.py 会在构建时生成 publications.jemdoc 和 site/papers/*.jemdoc，
请修改 JSON 而不是这些自动生成的 jemdoc 文件。每篇保留来源和待核实记录。
detail_page 为 false 的条目只在列表显示题目和作者，不加链接或状态标签；
以后需要详情页时，补齐期刊等资料并将此项改为 true。
菜单用 Code 显示软件页；Teaching 已加入课程与参与授课说明。
不要直接改 docs 内的 HTML；下次生成时会覆盖它们。
照片放在 site/images，论文 PDF 放在 site/papers，简历放在 site/files。
把文件放入文件夹后，还需要添加对应链接；论文的 Manuscript 链接可在 JSON
的 manuscript_url 中改为 PDF 文件名（与该论文 HTML 同在 papers 文件夹）。
首页头像暂时是浅灰空白占位；换照片时，把新照片放到 site/images，
并将 index.jemdoc 中 images/portrait-placeholder.svg 改成新照片路径。

3. 重新生成
双击 preview.cmd，生成后会打开首页。也可双击 build.cmd，只生成文件。
终端方式：在本项目目录运行 python -X utf8 build.py
若浏览器里已经打开页面，请刷新。

4. 写公式
行内示例：The norm is $\|x\|_2$.
独立公式示例（括号形式是 jemdoc 的语法）：
\(
  E = mc^2
\)
KaTeX 在生成网页时运行，不需要购买服务器或安装完整的 LaTeX。
并非所有 LaTeX 宏包、命令都受支持；如果生成报错，把公式发给我即可。

5. GitHub Pages 发布与更新
GitHub 账户已确认是 KeyJONE；不要发送密码、访问令牌或恢复码。
已使用的个人主页仓库名称是 keyjone.github.io。
免费账户可使用公开仓库；网站中的内容也会公开。
项目已提交到该仓库的 main 分支；后续更新也提交到这个分支。
Settings > Pages 已设置为 Deploy from a branch，main，/docs。
docs/.nojekyll 已准备好，GitHub 将直接发布生成的静态网页。
正式网址已验证可访问：https://keyjone.github.io/。
首页 Contact 的个人主页链接及显示文字已改成正式网址。
若以后采用自定义域名，需要同步更新 Contact 的链接。
后续每次修改 .jemdoc 后，都需要重新生成并上传最新的 docs。

6. 页面风格
按你的偏好参照 Stephen Boyd 的主页，使用白底、Helvetica 字体、蓝色标题，
以及一直位于左侧的浅灰导航。已取消最初的手机顶部导航切换。
窄窗口会保留桌面结构，可能需要横向滚动；放大窗口可看到完整布局。
照片区与 Boyd 主页一样，暂按 300×200 的横向比例留白。
当前菜单是 Home、Teaching、Biography，以及 Research 下的 Papers、Code、People。
不包含 Books、Classes、MOOC 及其课程链接；正文内容留待之后继续完善。
外观参考：https://web.stanford.edu/~boyd/index.html
site/boyd-base.css 保存参考页面公开的 jemdoc.css；custom.css 是本地补充样式。

文件夹用途
site/       你平时编辑的网页源文件
docs/       生成的成品网页，也是 GitHub Pages 发布目录
tools/      jemdoc-cvx 及 KaTeX，不需日常修改
downloads/  官方下载包及 SHA256 校验文件
runtime.local.json  本机 Node 路径，不提交到 GitHub

迁移到其他电脑
需要 Python 3.11+ 和 Node.js。
在 tools/jemdoc-cvx-1.0.0 中运行 npm install（或 pnpm install）。
回到项目根目录，运行 python -X utf8 build.py。
本机使用已有 Python 3.13.9 和 Node.js 24，KaTeX 为官方固定的 0.16.11。

来源与改动
官方版本：jemdoc-cvx v1.0.0。
https://github.com/cvxgrp/jemdoc-cvx/releases/tag/v1.0.0
保留原始 LICENSE、README 和下载包。
对 tools/jemdoc-cvx-1.0.0/jemdoc 做了 Windows 兼容调整：
通过 Node 直接调用 KaTeX CLI，并明确使用 UTF-8 读取公式输出。
同时修复 Windows CRLF 段落识别及链接 target 属性转义，外部内容在新标签页打开。
site/site.conf 增加手机视口，并改为使用本地 KaTeX 样式和字体。
